# ASA.DEV — Personal Portfolio

A bilingual (English/Arabic) personal portfolio website with a retro pixel-art aesthetic, built to showcase projects in Game Development and Artificial Intelligence.

🔗 **Live site:** [asadev-portfolio.vercel.app](https://asadev-portfolio.vercel.app)

## About

This portfolio belongs to **Abdullah Alhamed**, an Information Systems student at King Abdulaziz University with a focus on Game Development and AI.

## Features

- 🌐 Bilingual — toggle between English and Arabic (full RTL support)
- 🌓 Light/dark theme toggle
- 🎮 Pixel-art / retro terminal visual style
- 📂 Projects archive with category filtering (Game Dev, AI/ML, Cybersecurity)
- 🎓 Academic record section
- ✉️ Working contact form
- 📱 Fully responsive design

## Tech Stack

- HTML, CSS, JavaScript
- Google Fonts (Press Start 2P, Space Mono)
- Deployed on [Vercel](https://vercel.com)
